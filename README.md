📌 About the Project

KSP Arts – Art Gallery is a web development project focused on presenting artwork in an attractive digital gallery. It provides an engaging interface for exploring art and artist-related content.

✨ Features

- 🎨 Art Gallery Showcase
- 👩‍🎨 Artists Section
- 🔐 Authentication Pages
- 📩 Contact Page
- 🛠️ Admin-Related Functionality
- 📱 Responsive User Interface
- Clean and User-Friendly Design

🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Python
